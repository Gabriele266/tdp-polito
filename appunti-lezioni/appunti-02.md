
# Lezione 02

La **working copy** è la versione su cui sto lavorando attualmente (spesso la più aggiornata)

Possono essere **presenti anche più server** su cui hostare delle repository remote
Nella versione distribuita, ogni utente ha **l'intera copia della repository**, che poi allinea con quella degli altri.
Si assume che la repo contenuta nel server sia quella ufficiale, l'operazione di allineamento si chiama **push**. 

Ad ogni laboratorio e per l'esame vogliono che: 
- effettuiamo la fork della loro repo (così ho già tutti i file necessari)
- Clone su pc locale (anche direttamente con pycharm)
- Commit per i lavori
- Push sulla **mia repo remota**
